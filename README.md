# MCAT Tracker

A personal MCAT study tracker that runs in the browser.

- **Log**: record the 1–3 questions most worth reviewing (subject, topic, wrong or guessed), plus optional notes and a retest question.
- **Today**: due retests first, then one priority topic with a practice step, then a CARS task.
- **Retest**: closed-book retests scheduled 1 / 2 / 5 days out based on how you did.
- **CARS**: log whole passages (time and score) and single questions (type and trap), with daily JSTOR / Aeon reading picks.
- **Weekly review**: repeated topics, repeated CARS traps, and old weak spots you've since answered correctly.

All records are saved in your browser's local storage. Nothing is uploaded. Use **Settings → Backup** to move data between devices.

The whole app is one file, `index.html`, served with GitHub Pages.
